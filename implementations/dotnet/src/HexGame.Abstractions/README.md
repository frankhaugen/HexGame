# HexGame.Abstractions

Core interfaces and small value types for the **HexGame** authoritative-core pattern: commands in, ticks advance simulation, snapshots/deltas/effects out. This package does **not** include rendering, physics, transport implementations, or serialization.

See the repository [spec/hexgame-architecture.md](../../../spec/hexgame-architecture.md) for the normative architecture. This assembly is a **.NET reference shape** only; other languages may express the same seams differently.
