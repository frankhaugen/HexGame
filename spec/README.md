# HexGame specifications

This directory contains the HexGame architecture specifications.

## Normative document

- **[hexgame-architecture.md](hexgame-architecture.md)** — The authoritative specification. Requirements use BCP 14 keywords (**MUST**, **SHOULD**, **MAY**).

## Informative companion

- **[informative-overview.md](informative-overview.md)** — High-level narrative introduction. It is **not** normative; where they differ, `hexgame-architecture.md` wins.

## Versioning

Spec versions use semantic-ish labels in the document header (for example `0.1`). Breaking normative changes SHOULD increment the minor or major version and MUST be recorded in the repository root [CHANGELOG.md](../CHANGELOG.md).
